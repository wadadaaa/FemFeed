# FemFeed MVP Roadmap

Status: draft for human review
Linear issue: BIM-67
Last updated: 2026-06-08

## Roadmap intent

This roadmap turns the FemFeed MVP product brief into a concise sequence of phases. The MVP should prove that a trusted, women-centered discovery experience is useful before adding broader product surface area.

FemFeed MVP is a curated discovery product, not a social network. The roadmap intentionally excludes follows, followers, public user profiles, comments, DMs, likes, reposts, and user-generated social feeds.

## MVP phases and milestones

### Phase 1: Daily personalized feed

Goal: give users a focused daily place to discover relevant women-centered and feminist resources.

Milestones:

- Define the resource card fields: title, source, resource type, category, tags, summary, publication date, and outbound link.
- Create a daily feed experience that can show recent, useful resources from trusted sources.
- Add lightweight personalization based on selected interests, categories, and tags.
- Include sensible fallback recommendations for new users before enough preferences are known.

### Phase 2: Trusted curated sources

Goal: make source quality visible and keep the MVP centered on trust rather than popularity.

Milestones:

- Define the source record fields: name, URL, description, type, covered categories, region, language, trust status, review notes, and last reviewed date.
- Create an initial curated source list for human review.
- Establish simple curation criteria for source inclusion, review, and removal.
- Show clear attribution on every feed item.

### Phase 3: Tags and categories

Goal: create a taxonomy that supports personalization, browsing, filtering, and source discovery.

Milestones:

- Draft 10-15 top-level categories for the first MVP scope.
- Define starter tags for core domains such as rights, femtech, health, career, tech, startups, design, research, culture, communities, grants, events, opportunities, tools, and guides.
- Connect resources and sources to categories and tags.
- Add basic browsing or filtering by category and tag.

### Phase 4: Save and bookmark

Goal: let users keep useful resources for later without introducing social engagement mechanics.

Milestones:

- Add save and unsave actions for resource cards.
- Create a private saved-items view.
- Preserve enough metadata on saved resources to make them useful when users return later.
- Keep saves private by default in MVP.

### Phase 5: Collections

Goal: let users organize saved resources into private groups for personal use.

Milestones:

- Add private collection creation, rename, and delete flows.
- Let users add saved resources to one or more collections.
- Show collection detail pages for the signed-in user.
- Keep public or shareable collections out of MVP unless separately approved.

### Phase 6: Source discovery

Goal: help users browse trusted sources directly without turning sources into followable social accounts.

Milestones:

- Add a source directory that can be browsed by category, type, region, or language.
- Add source detail pages with description, coverage areas, trust status, and outbound website link.
- Avoid "follow" language and social graph mechanics.
- Support an internal or admin-reviewed path for future source suggestions if approved.

## MVP completion milestone

The MVP is ready for beta review when a user can:

1. Open FemFeed and see a personalized daily feed from trusted curated sources.
2. Understand why a resource is relevant through categories, tags, and attribution.
3. Save useful resources for later.
4. Organize saved resources into private collections.
5. Browse trusted sources without following people, accounts, or social profiles.

## Post-MVP decision gates

The following ideas require separate human review after the MVP proves the discovery experience:

- Public profiles or public collections.
- User submissions beyond admin-reviewed source suggestions.
- Community, discussion, commenting, messaging, or reaction features.
- Engagement-driven ranking based on likes, reposts, or popularity.
